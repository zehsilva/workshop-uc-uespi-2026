# Imersão UESPI: apresentação 

`UESPI_IA_Classico_LangChain_2026.tex`tem o conteudo técnico da apresentação sobre Bayes, LangChain e modelos locais e utiliza um design Beamer tradicional (`Madrid`, branco e azul).

## Compilar

```bash
xelatex UESPI_IA_Classico_LangChain_2026.tex
```

É necessário manter a pasta `assets/` ao lado do `.tex`. O notebook é o `UESPI_Workshop_Bayes_LangChain_Modelos_Locais_2026.ipynb`.

[link para google colab](https://colab.research.google.com/github/zehsilva/workshop-uc-uespi-2026/blob/main/UESPI_Workshop_Bayes_LangChain_Modelos_Locais_2026.ipynb)

O material contém dados sintéticos e protocolos de avaliação.
