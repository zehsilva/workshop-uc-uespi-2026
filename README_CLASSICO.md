# Imersão UESPI: apresentação académica clássica

A versão `UESPI_IA_Classico_LangChain_2026.tex` preserva o conteúdo técnico da apresentação sobre Bayes, LangChain e modelos locais, mas utiliza um design Beamer tradicional (`Madrid`, branco e azul), sem capa escura ou caixas decorativas.

## Compilar

```bash
xelatex UESPI_IA_Classico_LangChain_2026.tex
xelatex UESPI_IA_Classico_LangChain_2026.tex
```

É necessário manter a pasta `assets/` ao lado do `.tex`. Em Overleaf, escolher `XeLaTeX`. O notebook permanece `UESPI_Workshop_Bayes_LangChain_Modelos_Locais_2026.ipynb`.

O material contém dados sintéticos e protocolos de avaliação, não resultados de execução dos modelos externos.
